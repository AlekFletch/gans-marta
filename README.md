# Ганс и Марта — лендинг ресторана

Одностраничный сайт: герой, интерьер, меню, карта, контакты. Тёмная тема.

## Запуск

```bash
npm install
npm run dev
```

Открыть http://localhost:5173. Сборка — `npm run build`, папка `dist/` льётся на любой
статический хостинг.

## Что менять

Весь текст, цены, адрес и контакты лежат в одном файле — [src/data/content.js](src/data/content.js).
Меню и контакты перенесены с [gansmarta.ru](https://gansmarta.ru) — адрес, телефоны, почта
и координаты реальные, сверены по карте. Ссылка `contacts.booking` ведёт на телефон
(на сайте нет отдельной формы онлайн-брони) — замените на неё, если она появится.

Координаты карты — `place.coords` в формате `[широта, долгота]`, приближение — `place.zoom`.

### Фотографии

Разметка под снимки готова. Положите четыре файла в `public/` с такими именами:

| Файл | Где выводится | Что на снимке |
|---|---|---|
| `hero-bar.jpg` | главный экран | барная стойка: краны, бокалы, гости |
| `interior-zal.jpg` | «Зал» | зал с панорамными окнами |
| `interior-bar.jpg` | «Барная стойка» | барная зона с табуретами |
| `interior-detali.jpg` | «Детали интерьера» | потолок: вымпелы, шары, велосипеды |

Пока файла нет — карточка сама показывает декоративную подложку с монограммой
вместо битой картинки, так что страница не ломается.

Пути, тексты `alt` и кадрирование лежат в [src/data/content.js](src/data/content.js)
(`site.heroShot` и `interior.shots`). Поле `position` задаёт, какая часть снимка
остаётся видимой при обрезке: `center`, `60% center`, `center top` и т. п. —
правится в одну строку, если кадр обрезался неудачно.

Пропорции рамок: главный экран 4:3 (ограничен высотой экрана), «Зал» 3:4,
остальные 3:2. Снимок вписывается по `object-fit: cover`, поэтому подойдут
любые исходные пропорции — браузер обрежет сам.

## Дизайн-система

Палитра «Эспрессо и шампань» и шрифты — [src/styles/tokens.css](src/styles/tokens.css).
Контраст каждого цвета посчитан и записан в комментариях рядом со значением.

| Токен | Значение | Контраст на фоне | Назначение |
|---|---|---|---|
| `--cream` | `#EDE6DA` | 15.2:1 | основной текст |
| `--champagne` | `#C8B08A` | 9.0:1 | акцент: цены, ссылки, надзаголовки |
| `--muted` | `#9A8F7D` | 5.9:1 | вторичный текст |
| `--dim` | `#7A6E5C` | 3.8:1 | **только линии и декор**, не текст |

Шрифты: Tenor Sans в заголовках и логотипе (одно начертание — иерархия строится
кеглем и разрядкой, а не жирностью), Literata в тексте. Подключены через Google Fonts
в [index.html](index.html), кириллица есть у обоих.

## Структура

```
src/data/content.js        весь контент
src/styles/tokens.css      палитра, шрифты, отступы
src/styles/global.css      reset и утилиты (.eyebrow, .display, .num, .shell)
src/components/*.jsx       по компоненту на секцию, стили в .module.css рядом
```

Порядок секций задаётся в [src/App.jsx](src/App.jsx), пункты верхнего меню — массивом
`nav` в `content.js`.

Карта — библиотека Leaflet на тайлах CARTO Dark Matter, приведённых к тёплой гамме
CSS-фильтром. Ключи и регистрация не нужны, атрибуция OpenStreetMap и CARTO обязательна
по лицензии — не убирайте её из [src/components/MapSection.jsx](src/components/MapSection.jsx).
